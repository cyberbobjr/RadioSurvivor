# Plan de test en jeu — après la nuit du 2026-10-13

Tout ce qui suit est **testé hors jeu seulement** (bancs `lupa`, `run_all` 116 étapes vertes, luacheck 16/0). Les
commandes donnent les tags exacts de chaque suite : une suite lancée sans le bon tag rend « 0 test(s) ».

## Avant de commencer

1. Le mod de test est réinstallé (`python tools/install_tests.py`, fait à 01:41). **Quitter complètement le jeu et le
   relancer** : les suites ajoutées cette nuit n'existent pas dans une partie déjà démarrée.
2. Partie solo `rstest-…`, mode `-debug`, Living Knox activé. **Décocher « Invisible » et « Ghost mode »** du menu
   triche : les PNJ ne perçoivent pas un joueur invisible.
3. Pont lancé (`bridge/radio_bridge.py`) pour les lots C et D ; Signal Smoke actif si possible.
4. Lancer **une suite à la fois** (RST refuse une suite tant que la précédente tourne). Je lis `console.txt` et les
   rapports `Lua/batman_RadioSurvivor/tests/` : dites-moi « lot X fini ».
5. Les suites qui créent un groupe le logent **dans la maison où vous êtes** : la plupart exigent d'être à l'intérieur
   d'une maison (sinon SKIP « the player must stand inside a house »). Pour les routines, choisir un endroit calme
   (les PNJ font maintenant du bruit et attirent les zombies).

départ d'un membre seulement vers un personnage connu ; rendez-vous du passeur au ponton de Riverside entre 01:00 et
03:00 ; secours « à temps » = vrai dépôt puis départ de toute l'équipe ; munitions converties une pour une quand un
mod remplace une arme.
