# Captures en jeu utilisées

La présentation utilise des captures réelles de Project Zomboid, sans image générée par IA dans la page finale. Les surimpressions HTML (noms, dialogues, fiches, progression) sont des projections fictives de RadioSurvivor, pas des fonctionnalités capturées en jeu.

## Captures des projets locaux

Copies sans retouche des fichiers existants de l’utilisateur :

- `radio-ingame.png` : `MilitaryDrop/docs/guide/images/ingame-walkie-logistics.png`. Fenêtre radio réelle avec module MilitaryDrop, distinct du futur module RadioSurvivor.
- `fournitures-ingame.png` : `MilitaryDrop/docs/guide/images/ingame-crate-trunk.png`. Inventaires et ravitaillement MilitaryDrop. Ce visuel ne montre pas une livraison à un PNJ RadioSurvivor.
- `signal-ingame.png` : `SignalSmoke/docs/shot2.png`. Signaux colorés en jeu ; illustration du signal possible pour un rendez-vous, sans capture du passeur.

L’affichage peut recadrer les captures par CSS pour la mise en page ; les fichiers restent inchangés.
